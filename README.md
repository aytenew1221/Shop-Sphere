# 🛍️ ShopSphere — Online Shopping Application

ShopSphere is a React-based e-commerce application that allows users to browse products, search and filter products, add items to a shopping cart, and complete an order through a checkout process.

The project demonstrates React fundamentals including components, props, state management, React Router, Context API, forms, validation, localStorage, and reusable UI components.

## ✨ Features

## 🏠 Home

-Welcome/introduction section
-Featured products
-Product categories
-Promotional section
-Navigation to other pages

## 🛍️ Products

-Display products in reusable cards
-Search products
-Filter products by category
-Sort products
-View product details
-Add products to cart

## 🛒 Shopping Cart

-Display selected products
-Increase or decrease product quantity
-Remove products from the cart
-Calculate subtotal
-Calculate delivery fee
-Free delivery for orders of 5,000 ETB or more
-Standard delivery fee of 200 ETB
-Calculate the final order total
-Continue shopping or proceed to checkout

## 💳 Checkout

-The checkout page collects customer and order information.

## Customer Information

-Full name
-Ethiopian phone number
-Optional email address

## Payment Methods

-Telebirr — requires a valid Telebirr phone number.
-CBE — requires a CBE account number.
-Cash on Delivery.

## Delivery

-Physical delivery.
-Delivery location is required.
-Optional delivery notes.

## 📦 Order Management

-Generate a unique order number.
-Display order confirmation.
-Save the latest order to localStorage.
-Save order history to localStorage.
-Clear the cart after a successful order.

## 🛠️ Technologies

- React
- JavaScript
- React Router
- Context API
- CSS
- JSON
- LocalStorage
- Vite

Open the application at the URL provided by Vite.

## 🎯 Purpose

This project demonstrates React fundamentals, state management, reusable components, React Router, Context API, controlled forms, side effects, and responsive web design.
